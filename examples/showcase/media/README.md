# Showcase media fixtures

## LeClap canvas demo

`leclap-canvas.mp4` contains the recorded LeClap text-editing and canvas-drag interaction supplied by the companion brand-motion project (`public/captures/canvas-drag.mp4`). The recording shows a demonstration scene, not private user media. It is bundled so the Web App Promo preview can be regenerated without access to that workspace.

The top 72 pixels of the marketing navigation were cropped for framing; the editor and its recorded interaction are retained. The recording is normalized to 30 fps and its last frame held for 0.2 seconds to cover the 6.4-second scene. It has no audio: the promo’s authored music supplies the soundtrack.

## Moo Mug

`moo-mug.mp4` is the portrait cow-cup demonstration clip used in the earlier product previews. It reuses the fictional Moo Mug illustration from [`demo-shop/index.html`](../../agentic-pr-video/demo-shop/index.html). The 720×1280, eight-second clip is bundled here so Product Launch renders can be reproduced without ignored scratch files. It has no source audio; the template supplies its authored music. The name, tagline and EUR 24 offer are illustrative demo copy.
