# Template posters

These small bundled stills come from the matching LeClap showcase renders in `apps/leclap-web/public/videos/showcase`. They work offline and preserve the full source frame in the native gallery. After regenerating a sample render, copy its `.webp` here and update `src/features/templates/template-posters.ts` if its catalog ID is new. The existing sample-render pipeline remains the source of the artwork.
